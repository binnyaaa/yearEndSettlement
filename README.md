# 그림 연말정산 · 年末精算

한 해 동안 그린 그림을 1月부터 12月까지 12칸에 채워서 **한 장의 PNG**로 저장하는 웹 페이지입니다.
빌드 과정 없이 `index.html` 파일 하나로 동작합니다.

## 기능

- **12칸 템플릿**: 6×2 칸에 1月~12月 태그가 붙어 있고, 제목은 `年末精算`입니다.
- **그림 넣기**
  - 빈 칸을 클릭해서 이미지를 하나씩 고를 수 있습니다.
  - **여러 장 한 번에 넣기**: 고른 파일을 이름 순서(숫자를 숫자 크기대로 정렬)대로 빈 칸에 채웁니다.
  - 파일을 칸 위로 드래그 앤 드롭하면 그 칸부터 채워집니다.
- **그림 위치·크기 조절**
  - 드래그로 위치를 옮깁니다.
  - 마우스 휠이나 크기 슬라이더로 1~3배까지 확대합니다.
  - 칸을 선택하면 **맞춤**(원래대로), **교체**, **비우기**를 할 수 있습니다. 더블클릭해도 교체됩니다.
- **배경색**
  - 예시 색 6개 중에서 고를 수 있습니다.
  - 컬러 피커(무지개 버튼)나 HEX 코드(`#e8e6e3`) 입력으로 아무 색이나 쓸 수 있습니다.
  - 어두운 배경을 고르면 제목 글자색이 자동으로 밝게 바뀝니다.
- **서명**: 닉네임을 넣으면 오른쪽 위에 표시됩니다(선택 사항).
- **PNG로 저장**: 2000×1250px로 내보냅니다. 화면에만 보이는 `+` 표시와 선택 테두리는 저장 이미지에 들어가지 않습니다.
- **전체 비우기**: 실수로 지우지 않도록 두 번 눌러야 비워집니다.
