# 그림 연말정산 · 年末精算

한 해 동안 그린 그림을 1月부터 12月까지 12칸에 채워서 **한 장의 PNG**로 저장하는 웹 페이지입니다.
빌드 과정 없이 `index.html` 파일 하나로 동작합니다.

## 기능

- **12칸 템플릿**: 6×2 칸에 1月~12月 태그가 붙어 있고, 제목은 `年末精算`입니다.
- **그림 넣기**
  - 빈 칸을 클릭해서 이미지를 하나씩 고를 수 있습니다.
  - **여러 장 한 번에 넣기**: 고른 파일을 이름 순서(숫자를 숫자 크기대로 정렬)대로 빈 칸에 채웁니다.
  - 파일을 칸 위로 드래그 앤 드롭하면 그 칸부터 채워집니다.
- **그림 위치·크기 조절**
  - 드래그로 위치를 옮깁니다.
  - 마우스 휠이나 크기 슬라이더로 1~3배까지 확대합니다.
  - 칸을 선택하면 **맞춤**(원래대로), **교체**, **비우기**를 할 수 있습니다. 더블클릭해도 교체됩니다.
- **배경색**
  - 예시 색 6개 중에서 고를 수 있습니다.
  - 컬러 피커(무지개 버튼)나 HEX 코드(`#e8e6e3`) 입력으로 아무 색이나 쓸 수 있습니다.
  - 어두운 배경을 고르면 제목 글자색이 자동으로 밝게 바뀝니다.
- **서명**: 닉네임을 넣으면 오른쪽 위에 표시됩니다(선택 사항).
- **PNG로 저장**: 2000×1250px로 내보냅니다. 화면에만 보이는 `+` 표시와 선택 테두리는 저장 이미지에 들어가지 않습니다.
- **전체 비우기**: 실수로 지우지 않도록 두 번 눌러야 비워집니다.

## 실행

```bash
# 브라우저로 바로 열기
open index.html

# 또는 로컬 서버로 실행
python3 -m http.server 8000
# → http://localhost:8000
```

GitHub Pages, Netlify, Vercel 같은 정적 호스팅에 `index.html`만 올려도 됩니다.

## 구조

```
index.html   # 마크업 + 스타일 + 스크립트 전부
README.md
```

### 스크립트 주요 부분

| 이름 | 역할 |
| --- | --- |
| `layoutC()` | 12칸의 좌표와 크기(x, y, w, h)를 계산합니다 |
| `renderC(screen)` | 배경, 제목, 칸, 월 태그를 캔버스에 그립니다. `screen=false`이면 저장용으로 그립니다 |
| `drawImg()` | 칸을 꽉 채우도록(cover) 맞춘 뒤 사용자가 조절한 확대·위치를 적용해 그립니다 |
| `state.imgs[i]` | 칸마다 `{ img, z, ox, oy }`(이미지, 확대 배율, 칸 대비 x·y 이동량)를 저장합니다 |
| `setBg()` | 배경색을 바꾸고 예시 색·피커·HEX 입력을 서로 맞춥니다 |

### 자주 고칠 값

- **캔버스 크기**: 스크립트 맨 위 `const W=2000,H=1250`
- **칸 크기·간격**: `layoutC()` 안의 `x0`(바깥 여백), `gap`(칸 사이), `h`(칸 높이), 줄 시작 y값 `r?728:200`
- **제목 문구**: `const TITLE='年末精算'`
- **예시 배경색**: `swatches()` 안의 색상 배열

## 참고

- 글꼴은 Google Fonts에서 불러옵니다(Noto Serif KR, Noto Sans KR). 오프라인에서는 시스템 기본 글꼴로 그려집니다.
- 업로드한 이미지는 브라우저 안에서만 처리되고 어디에도 전송되지 않습니다. 새로고침하면 사라집니다.
- PNG 저장은 Claude 아티팩트 안에서는 `claude.use("downloads")`를 쓰고, 그 밖에서는 이미지를 새 탭으로 엽니다. 브라우저에 따라 바로 다운로드될 수도 있습니다.
- `renderA` / `renderB`는 초기 시안 코드로, 지금은 쓰이지 않습니다.
